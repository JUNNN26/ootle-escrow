OotleEscrow — trust-minimized escrow for P2P trades

DEMO MODE — walletless simulation. No wallet, no funds, no chain. The state machine below mirrors the Ootle template in src/lib.rs rule-for-rule (same methods, same rejection messages; pinned by the parity tests in demo/parity.test.mjs).

The trade: the buyer pays 1,000 XTM for an item the seller ships off-chain. A named arbitrator can settle disputes. If the trade is still open at epoch 100, the buyer can reclaim the payment.

Walkthroughs (≈3 min)

  1. Happy path: as Buyer → Fund, then Release. The seller is paid in full.
  2. Wrong signer: Reset, act as Seller → Fund is rejected (“Only the buyer can fund the escrow”).
  3. Dispute: Reset, as Buyer → Fund; as Seller → Open dispute; try Release (locked out); as Arbitrator → Resolve → buyer.
  4. Timeout: Reset, as Buyer → Fund; set epoch to 100 → Claim timeout refund.
